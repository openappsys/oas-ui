# OAS-UI 愿景（Vision）

> 状态：初稿。本文档是产品档案的根，派生 ROADMAP / PRD / 技术架构。

## 1. 一句话愿景

一套**框架无关、独立可用、TypeScript 优先**的开源通用 UI 组件库：以 Web Components 为运行时载体，兼顾 React / Vue / 原生 / Svelte 等任何宿主，让"同一套组件"在任何前端栈里开箱即用。

## 2. 为什么存在（动机）

- 前端框架十年四换（jQuery → Angular → React → Vue → 新一轮），每个框架都重复发明一套组件，但**交互行为与设计语言是相通的**。
- 现有主流组件库多绑定单一框架（或只支持 Vue、或只支持 React）。跨栈团队、微前端、长期演进的项目被迫维护多套实现。
- Web Components 已是浏览器原生标准（Custom Elements + Shadow DOM），2024 年后各大框架均已补齐互操作，正是"框架无关组件库"的成熟窗口期。
- AI 辅助开发（TDD + 并行 agent）让一人团队做到过去一个小组的工作量成为可能。

## 3. 目标（做什么）

| 维度   | 目标                                                                                                    |
| ------ | ------------------------------------------------------------------------------------------------------- |
| 运行时 | Web Components（Custom Elements + Shadow DOM），无框架运行时依赖，`<oas-button>` 直接可用               |
| 语言   | TypeScript 全量覆盖，导出 `.d.ts`，属性/事件有完整类型                                                  |
| 工程   | Vite 构建 + Vitest 单测 + Playwright 视觉/交互测试                                                      |
| 主题   | CSS 变量设计 token + 多主题（light/dark）+ 自定义主题能力                                               |
| 国际化 | 框架无关 locale registry（不依赖 vue-i18n/react-intl）、语言包 tree-shakable、Intl.* 格式化、RTL 支持   |
| 覆盖   | 通用组件库覆盖：表单、反馈、数据展示、布局、导航（v1.0 核心集 68 件，v1.x 长尾推进至约 115~120 件） |
| 发布   | 语义化版本、文档站、demo、变更日志、可 tree-shaking                                                      |

## 4. 非目标（不做什么，守住边界）

- 不做框架绑定：**不为 React/Vue 单独出 wrapper 版本**（Web Components 本身可互操作；如社区需要 adapter 可作为独立子包）
- 不做应用级功能：路由、状态管理、数据请求、SSR 数据预取
- 不内置图标字体：图标走内联 SVG（可 tree-shake）
- 初期不做 SSR 优先渲染支持（Web Components 的 SSR 属后续增强项，见 ROADMAP）
- 不追求"全量 70+ 组件"一次性做完：按核心集分批交付，宁精勿滥

## 5. 设计原则

1. **原生优先**：能用地（大多数）组件直接用 `type=checkbox`、`<select>`、`<dialog>` 等原生语义/元素，不重新发明轮子——可访问性、键盘行为、屏幕阅读器免费获得。
2. **无依赖优先**：运行时不依赖第三方运行时库；若需（如定位浮层）优先内联实现或选择 MIT 最小依赖，可控体积。
3. **API 对称**：属性命名对齐主流组件库的生态习惯，降低迁移成本（如 `size`、`disabled`、`loading`、`type`）。
4. **事件即接口**：组件对外通信统一走 CustomEvent，命名 `oas-*` 前缀避免冲突。
5. **可访问性即验收项**：每个组件必须过键盘导航 + ARIA + 屏幕阅读器基本检查，否则不算完成。
6. **Shadow DOM + ::part 暴露**：样式隔离默认，但通过 `::part()` 与 CSS 变量开放定制点。
7. **文档与代码同源**：组件 doc 注释、demo、测试三位一体，文档站由源码生成。
8. **性能领先**：性能是一等目标——首包体积、组件渲染耗时、交互响应必须可测量、有基准、有门槛（CI 体积/耗时预算不退化）；体积预算两层制（全量天花板 + 按需绝对值），对自身基线逐版本不退化、持续更优。每个版本发布前核对基准。

## 6. 成功标准（愿景层面，v1.0 复盘用）

> 现状（v1.0.0 已发布）：68 组件全绿（单测 + 视觉回归 + axe），文档站上线，双许可（MIT OR Apache-2.0），React + Vue playground 双宿主跑通。

- v1.0.0 发布：核心 68 组件全绿（单测 + 视觉回归），文档站上线，`npm i` 三行代码可用
- 至少 2 个不同框架的示例项目（React + Vue）用同一套组件跑通真实页面
- 一次基础改动（如 token 换肤）不回归既有宿主应用
- 社区可反馈、可贡献：issue 模板、贡献指南、CI 就绪
