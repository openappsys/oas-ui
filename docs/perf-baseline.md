# 性能基准（OAS-UI）

> 状态：初稿，2026-08-12 首测。
> 结构化数据（机器可读）见 [`docs/perf-baseline.json`](./perf-baseline.json)（生成物，由 `scripts/perf/` 写入）；本文档是对比口径、对照与预算依据的说明。
> 对应原则：`docs/vision.md` §5.8「性能领先」——性能可测量、有基准、有门槛（CI 体积预算），对自身基线逐版本不退化、持续更优。

## 1. 量纲与口径

| 项         | 口径                                                                                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 压缩       | gzip = zlib 默认档；brotli = zlib q11（HTTP/1.1 CDN 常见档）                                                                                                   |
| 全量入口链 | `import '@oas-ui/ui'`（dist/index.js）的静态 import 闭包，逐文件压缩求和（**上界估计**）                                                                     |
| 单组件链   | `import '@oas-ui/ui/<目录>'` 的静态 import 闭包（入口 + 依赖），逐文件压缩求和（浏览器原生 ESM 逐文件加载的上界；经打包器合并后单文件 gzip 更低，见 cdn.js） |
| 渲染耗时   | happy-dom 合成环境（非真实浏览器渲染口径），100 次迭代的均值/中位数/p95（ms）                                                                                  |
| 基线日期   | 2026-08-23（体积；渲染段 2026-08-21），node v23.8.0                                                                              |

刷新命令：先 `pnpm build`，再 `pnpm perf:size` / `pnpm perf:bench`（两脚本各自 merge 写回同一个 JSON，互不覆盖）。

### 单组件按需引入链（tree-shaking 叙事验证）

| 组件   | 入口                        | 文件数 | raw     | gzip    | brotli  |
| ------ | --------------------------- | ------ | ------- | ------- | ------- |
| button | `@oas-ui/ui/basic/button` | 51     | 57.6 KB | 22.0 KB | 18.5 KB |
| table  | `@oas-ui/ui/data/table`   | 14     | 99.0 KB | 31.2 KB | 26.1 KB |
| form   | `@oas-ui/ui/form/form`    | 9      | 31.1 KB | 12.5 KB | 10.2 KB |

**tree-shaking 叙事成立**：按需引入单组件链 gzip 12.5~~22.0 KB，仅为全量入口（405.7 KB gzip）的 3~~6%；全量单文件 cdn.js（234.9 KB gzip）即包含全部约 120 个组件 + 运行时。

**固定开销拆分**（以 button 链为例，51 个文件）：

- 组件本体（oas-button.js + index.js）≈ 29 KB raw（v2.1.x button 全能力增强后）；
- @oas-ui/core 基类运行时 ≈ 11.5 KB raw（5.9 KB gzip）；
- @oas-ui/icons 图标注册表（含全部 40+ 图标路径）≈ 17.4 KB raw（9.7 KB gzip）——`iconRegistry` 对象字面量引用全部图标，打包器无法摇掉（已知优化方向：图标名子路径按需导出）。

## 3. 自评摘要

### 体积（2026-08-23）

| 口径           | 实测                                        | 自评                                                                                        |
| -------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 全量           | cdn.js 234.9 KB；全量入口链 405.7 KB（上界） | 天花板 300/520 KB 内随能力增长，预警线 270/468 KB（§4）                                     |
| 按需（button） | 22.0 KB（含 core + 全量图标注册表）         | 预算 26 KB 内；固定开销拆分见 §2（core 5.9 KB + icons 9.7 KB gzip）                         |
| 主题           | 2.6 KB gzip（index.css）                    | 一套语义 token 变量即全部主题成本；组件样式内联进组件，无独立样式文件                        |
| 图标集         | 9.7 KB gzip（40+ 图标）                     | 预算内；图标名子路径按需导出是已知优化方向（结论 3）                                         |

### 渲染耗时（happy-dom，median/p95，ms）

| 场景                          | 实测        | 门槛（§4 渲染预算） |
| ----------------------------- | ----------- | ------------------- |
| button 首渲染                 | 0.08 / 0.16 | 5 ms                |
| table 100 行首渲染            | 21.9 / 37.9 | 50 ms               |
| select 100 选项首渲染         | 6.6 / 11.4  | 50 ms               |
| table 数据更新（100 行换新）  | 18.6 / 16.9 | 50 ms               |
| select 选项更新（100 项换新） | 6.8 / 29.0  | 50 ms               |

> 渲染口径诚实声明：happy-dom 无排版/合成管线，数值仅供**相对对比与退化监测**；真实浏览器首帧数字需另行用 Playwright/Lighthouse 建立基线后评估。

### 结论（对照 vision §5.8）

1. **体积**：按需口径（12~~22 KB/组件）保持轻量；全量口径在两层制预算内随组件能力增长，纪律由单组件链绝对值预算守住。
2. **渲染**：合成环境数据仅作退化监测，全部场景 p95 在门槛内；真实浏览器基线待补。
3. **两个已知优化方向**（非本次范围，记录供后续排期）：
   - 图标注册表导致任一组件链都带全量图标（约 10 KB gzip）——可按图标名做子路径按需导出（`@oas-ui/icons/check`）；
   - 全量入口链逐文件 gzip 265 KB 是上界，浏览器/打包器实测会更低，可考虑提供官方按需打包配置示例。

## 4. 预算与门槛

### 体积预算（CI 强制，`pnpm perf:size` 超预算非零退出）

**两层制（2026-08-23 定夺）**：

- **全量类 = 天花板制**（cdn.js / 全量入口链）：组件能力持续增强，体积随之增长属预期内行为，天花板只为防灾难性膨胀；达 90% 预警线（WARN，不拦截）时启动瘦身评估（portal/shadow 公共运行时抽取、图标子路径导出等）或再定档；
- **单组件链与 theme = 绝对值制**（实测 + 上浮约 15~20%）：守住按需引入叙事的纪律，超预算即 FAIL。

| 预算项                    | 实测 gzip | 预算（制式）       | 依据                                                                                          |
| ------------------------- | --------- | ------------------ | --------------------------------------------------------------------------------------------- |
| dist/cdn.js               | 240,557 B | 300 KB（天花板）   | 2026-08-23 定档：预留后续版本能力增长空间；预警线 270 KB                                    |
| @oas-ui/ui 全量入口链   | 415,403 B | 520 KB（天花板）   | cdn 天花板 300 KB × 链/单文件实测比 ≈1.73（逐文件求和上界）；预警线 468 KB                  |
| button 链                 | 22,556 B  | 26 KB（绝对值）    | 实测上浮约 15%（含 core + 全量 icon 注册表，v2.1.3 能力增强后）                              |
| table 链                  | 21,801 B  | 26 KB（绝对值）    | 实测上浮约 19%（含 core + virtual-list + i18n，v2.0/v2.1 表格能力增强后）                    |
| form 链                   | 12,831 B  | 14 KB（绝对值）    | 实测上浮约 12%                                                                                |
| @oas-ui/theme index.css | 2,680 B   | 3 KB（绝对值）     | 实测上浮约 14%（v2.1 预设文字 -text token + dark 语义色修复后）                              |

### 渲染预算（本地/发布前，`pnpm perf:bench` 量级防退化）

阈值取多轮实测 p95 的约 3~5 倍取整（happy-dom 下耗时跨轮次波动明显）：button 5 ms / input 15 ms / table 100 行 50 ms / select 100 选项 50 ms / tabs 10 面板 15 ms / form 10 字段 40 ms / table 数据更新 50 ms / select 选项更新 50 ms。渲染耗时波动大，**不进 CI**。
