# 性能基准（OAS-UI）

> 状态：初稿，2026-08-12 首测。
> 结构化数据（机器可读）见 [`docs/perf-baseline.json`](./perf-baseline.json)（生成物，由 `scripts/perf/` 写入）；本文档是对比口径、对照与预算依据的说明。
> 对应原则：`docs/vision.md` §5.8「性能领先」——性能可测量、有基准、有门槛（CI 体积预算），目标领先同类库、保底平齐。

## 1. 量纲与口径

| 项         | 口径                                                                                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 压缩       | gzip = zlib 默认档；brotli = zlib q11（HTTP/1.1 CDN 常见档）                                                                                                   |
| 全量入口链 | `import '@oas-ui/ui'`（dist/index.js）的静态 import 闭包，逐文件压缩求和（**上界估计**）                                                                     |
| 单组件链   | `import '@oas-ui/ui/<目录>'` 的静态 import 闭包（入口 + 依赖），逐文件压缩求和（浏览器原生 ESM 逐文件加载的上界；经打包器合并后单文件 gzip 更低，见 cdn.js） |
| 渲染耗时   | happy-dom 合成环境（非真实浏览器渲染口径），100 次迭代的均值/中位数/p95（ms）                                                                                  |
| 基线日期   | 2026-08-12，node v23.8.0                                                                                                                                       |

刷新命令：先 `pnpm build`，再 `pnpm perf:size` / `pnpm perf:bench`（两脚本各自 merge 写回同一个 JSON，互不覆盖）。

### 单组件按需引入链（tree-shaking 叙事验证）

| 组件   | 入口                        | 文件数 | raw     | gzip    | brotli  |
| ------ | --------------------------- | ------ | ------- | ------- | ------- |
| button | `@oas-ui/ui/basic/button` | 51     | 38.4 KB | 17.5 KB | 14.6 KB |
| table  | `@oas-ui/ui/data/table`   | 10     | 48.9 KB | 17.5 KB | 14.4 KB |
| form   | `@oas-ui/ui/form/form`    | 9      | 27.9 KB | 11.6 KB | 9.4 KB  |

**tree-shaking 叙事成立**：按需引入单组件链 gzip 11.6~~17.5 KB，仅为全量入口（265 KB gzip）的 4~~7%；全量单文件 cdn.js（113 KB gzip）即包含全部约 115 个组件 + 运行时。

**固定开销拆分**（以 button 链为例，51 个文件）：

- 组件本体（oas-button.js + index.js）≈ 3 KB raw；
- @oas-ui/core 基类运行时 ≈ 11 KB raw（4.9 KB gzip）；
- @oas-ui/icons 图标注册表（含全部 40+ 图标路径）≈ 18 KB raw（9.9 KB gzip）——**是单组件链的主要膨胀项**，因为 `iconRegistry` 对象字面量引用全部图标，打包器无法摇掉。

## 3. 横向对比（中性口径）

> 下列参考值为公开体积分析站点（bundlephobia 类）的约略数据，跨版本/口径存在差异，一律标「约」；渲染耗时各库自测口径不一，无统一公开基准，仅给量级参考。

### 体积

| 口径             | 我们（2026-08-12 实测）                  | 参考对象公开数据（约）                                                                                                                                                                                                                      | 结论                                                                                            |
| ---------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 全量 gzip        | cdn.js 113 KB；全量入口链 265 KB（上界） | 企业级单框架组件库（React 生态）：全量 ESM + 样式 gzip 约 350~~450 KB；企业级单框架组件库（Vue 生态）：约 250~~350 KB；企业级原子化风格组件库（React 生态）：约 150~~250 KB（样式另计）；原生 Web Components 组件库（同类）：约 150~~300 KB | **领先**：即便按上界 265 KB 也低于 React/Vue 单框架全量量级；单文件 113 KB 与 WC 同类持平或更优 |
| 按需 button gzip | 17.5 KB（含 core + 全量图标注册表）      | 企业级单框架组件库（React 生态）：button 按需约 15~~30 KB；企业级单框架组件库（Vue 生态）：约 10~~20 KB                                                                                                                                     | **平齐**：量级相当；组件本体小，固定开销来自 core 运行时与图标集                                |
| 主题             | 1.4 KB gzip（index.css）                 | 各主流库样式 gzip 约 10~100 KB（含 reset/组件样式）                                                                                                                                                                                         | **领先**：token 体系仅一套语义变量，组件样式内联进组件                                          |
| 图标集           | 9.9 KB gzip（40+ 图标）                  | 各主流库图标集全量 gzip 约 10~50 KB                                                                                                                                                                                                         | **平齐/领先**                                                                                   |

### 渲染耗时

| 场景                          | 我们（happy-dom，median/p95，ms） | 参考量级（约）                                                                              | 结论                                 |
| ----------------------------- | --------------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------ |
| button 首渲染                 | 0.08 / 0.16                       | 各库单控件首渲染普遍 < 5 ms                                                                 | 平齐                                 |
| table 100 行首渲染            | 7.7 / 10.9                        | 企业级单框架组件库（React 生态）100 行表格首渲染常见约 10~50 ms（含框架调度与虚拟滚动开销） | 领先量级，但口径不同需真实浏览器复核 |
| select 100 选项首渲染         | 6.6 / 11.4                        | 约 10~30 ms                                                                                 | 领先量级                             |
| table 数据更新（100 行换新）  | 10.4 / 20.5                       | 约 10~50 ms                                                                                 | 平齐量级                             |
| select 选项更新（100 项换新） | 6.8 / 29.0                        | 约 10~40 ms                                                                                 | 平齐量级                             |

> 渲染口径诚实声明：happy-dom 无排版/合成管线，数值仅供**相对对比与退化监测**；真实浏览器首帧数字需另行用 Playwright/Lighthouse 建立基线后评估。上表"参考量级"为公开分享与社区基准的粗略区间，标「约」，不作硬性对比结论。

### 结论（对照 vision §5.8）

1. **体积维度：领先**。全量口径（单文件 113 KB gzip）显著小于 React/Vue 单框架全量（约 300~~450 KB gzip），与原生 Web Components 同类持平或更优；按需口径（11.6~~17.5 KB）与主流库平齐。
2. **渲染维度：暂评"平齐偏领先量级"**。合成环境数据仅作门槛监测，真实浏览器基线待补；当前量级未现明显落后迹象。
3. **两个已知优化方向**（非本次范围，记录供后续排期）：
   - 图标注册表导致任一组件链都带全量图标（约 10 KB gzip）——可按图标名做子路径按需导出（`@oas-ui/icons/check`）；
   - 全量入口链逐文件 gzip 265 KB 是上界，浏览器/打包器实测会更低，可考虑提供官方按需打包配置示例。

### 渲染预算（本地/发布前，`pnpm perf:bench` 量级防退化）

阈值取多轮实测 p95 的约 3~5 倍取整（happy-dom 下耗时跨轮次波动明显）：button 5 ms / input 15 ms / table 100 行 50 ms / select 100 选项 50 ms / tabs 10 面板 15 ms / form 10 字段 40 ms / table 数据更新 50 ms / select 选项更新 50 ms。渲染耗时波动大，**不进 CI**。
