# oas-logistics 设计前必答

1. **取消路径**：无浮层、无异步、无计时器；折叠切换是纯 attribute 回写（`collapsed` 增删）+ 同帧重渲染 + 派 `oas-toggle`，无中间态；动作区（复制单号 / 复制地址）的复制逻辑归宿主（组件只提供槽位与布局），无剪贴板写入面即无失败面。渲染签名比对（steps 内容 + 折叠态）未变化时不重建 li——无重复构建产物。
2. **属性默认值/空态**：`steps` 缺省 / 非法 JSON → 空列表（渲染 i18n 空态「暂无物流信息」，非法告警一次）；缺 `title` 且缺 `desc` 的条目忽略（条目最小可识别单元）；`reverse` 缺省关（数据最新在顶惯例）；`collapsed` 缺省关；steps ≤2 条时**切换钮隐藏**（无可折叠内容不渲染空钮）；state 缺省按序推导（见下）。
3. **多步交互失败点**：折叠一步完成（点击 → 回写 attribute → 重渲染 → 派 `oas-toggle`，detail `{ collapsed }` 为切换后状态）；状态推导是纯函数（无歧义路径）；`reverse` + `collapsed` 组合有确定语义——折叠永远截取**数据前 2 条**（最新，与渲染方向无关），再按 reverse 方向渲染。
4. **破坏性选项**：无破坏性动作；steps 数据归宿主，组件不删改。
5. **键盘/ARIA**：时间线 `ol > li` 合法组合（ol 天然 list 语义 + `aria-label` i18n；**切换钮 / 动作区 / 空态都在 ol 之外**——非条目节点不进列表语义，对齐品类首波 list 语义教训）；当前节点 `aria-current="step"`；每个 li `aria-label` 携带状态文本（i18n 已完成 / 进行中 / 待完成——**节点状态不只靠颜色**，读屏可读）+ title / time / desc 拼接全内容；视觉上 current 点径更大 + 标题加重（非唯色彩通道）；切换钮可见文本即状态（「展开全部 N 条」/「收起」）；动作区 `role="group"` + `aria-label`（相关操作）；节点连接线 CSS 伪元素 `aria-hidden` 不进语义。
6. **受控/非受控与宿主桥接**：`steps` get+set 访问器（setter 容忍数组与 JSON 字符串并反射 attribute），Vue/React 按 property 赋值不丢数据；`collapsed` get+set 双通道（宿主直写静默，用户点击才回写 + 派发——受控与非受控同一通道不回环）；`reverse` 走原生 attribute 存在性通道；属性名避开 DOM 内建（`steps` / `reverse` / `collapsed` 均无 HTMLElement 原型成员冲突）。

## 状态推导规则（缺省按序推导的精确口径）

数据惯例「最新在前」（首条 = 最新进展）。三条规则可测可解释：

- **全部未声明 state** → 轨迹型缺省：首条 = `current`（最新进展），其余 = `done`（已发生历史）。
- **有显式声明** → 未声明条目以「首个显式 `current` / `pending` 条目」为界：声明序在其之前的未声明条目 = `done`，之后的 = `pending`（全流程节点型：未到节点的自然语义）。
- **只声明 `done`**（无 current / pending）→ 未声明条目 = `done`；非法 state 字符串视同未声明并一次性 devWarn。

## 预留能力面（包体分级：本体冻结在大众功能集）

- **地图轨迹联动**（配送地图 + 时间线双向高亮）。
- **复制动作内建**（组件托管剪贴板写入与「已复制」反馈——当前归宿主）。
- **多包裹切换**（子单 / 母单维度分组）。

当前本体接口（slot / attribute）对上述能力保持开放。
