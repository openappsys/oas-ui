# oas-price 设计前必答

1. **取消路径**：纯展示组件，无操作、无浮层、无孤儿产物；无值时不渲染价格（不残留空 part）。
2. **属性默认值/空态**：`currency` 默认 `CNY`、`precision` 默认 2、`size` 默认 `md`、`locale` 缺省取文档 `lang` 再退 `zh-CN`；空值/非法数字 → 空态；非法币种 → 回退默认；非法趋势 → 不渲染趋势。
3. **多步交互失败点**：无多步交互（Intl 构造用 try/catch 兜底，非法 locale/币种不抛错）。
4. **破坏性选项**：无破坏性行为；空值渲染空而非 0，避免误导。
5. **键盘/ARIA**：无交互元素；金额按 Intl 部件顺序输出为连续可读文本；趋势箭头 `aria-hidden`，方向与涨跌由 visually-hidden 文案承载；原价带「原价」前缀；`<s>` 保留删除线语义。
6. **受控/非受控与宿主桥接**：纯属性驱动（无内部状态），Vue/React 绑定属性即可；币种/精度/语言切换即时重渲染。
