# SafeArea 设计前必答

1. **取消路径**：纯展示件，无操作可取消；不创建浮层/监听器，无孤儿产物。
2. **属性默认值**：`position` 缺省 `bottom`；`size` 缺省读取 `env(safe-area-inset-*)`（不支持时 0）。0 高度是合法空态。
3. **多步交互**：无。无失败点、无加载/禁用态。
4. **破坏性选项**：无。显式 `size` 只影响自身占位高度，不改变页面其他布局。
5. **键盘 / ARIA**：无键盘焦点、无交互语义；插槽装饰内容可访问性由宿主决定。
6. **受控 / 宿主桥接**：无 JS property；`position` / `size` 均为标准 attribute，Vue / React 直接透传。
