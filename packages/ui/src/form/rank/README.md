# oas-rank 组件说明

排序题（form 族）：点击 / 键盘把选项加入排名序列，已选项显示名次徽标并可上移 / 下移 / 取消。设计前必答清单：

1. **取消路径**：无浮层、无全局监听、无计时器；`clear()` 清空排名。重建后的 DOM 由事件委托驱动，不残留监听；交互后焦点归还语义等价的新按钮（键盘流不中断；**鼠标点击同样归还焦点**，不区分输入方式——`focus()` 对鼠标用户无副作用，换来单一代码路径）。
2. **属性默认值 / 空态**：`value` 缺省 `[]`（部分排名合法）；`min-ranks` 缺省不校验（非法值忽略并告警一次）；`min-ranks` 超过可加入的选项总数时一次性告警「下限不可达」（禁用项不计入总数，只提示不拦截渲染——数据可能后续补齐）；`options` 缺省为空并渲染「暂无数据」占位。
3. **多步交互**：加入（点选项 / 回车）→ 写回 `value` → 重建排名区与可选区 → 更新徽标 / 边界按钮 → `aria-live` 播报 → 派发 `oas-change`。失败点在下限校验：`validate()` 未达 `min-ranks` 时返回 false 并派发 `oas-invalid`，错误显示后继续作答会静默复检。
4. **破坏性选项**：无破坏性操作；移除 / 清空只影响排名序列，不改选项本身。`disabled` 选项不可加入，组级 `disabled` / `readonly` 在入口处拦截。
5. **键盘可达 / ARIA**：选项与上移 / 下移 / 移除都是原生 `button`（Tab + Enter/Space）；调整按钮的可访问名带选项名（同名按钮可区分）；名次变化经 `aria-live="polite"` 播报；名次徽标与间距使用逻辑属性，RTL 自动镜像。不依赖拖拽。
6. **受控 / 非受控与宿主桥接**：`options` / `value` 为 get+set 双通道（数组 property + JSON attribute 双容忍，赋值即生效、不派发事件）；用户交互才派发 `oas-change`。属性名不与 `HTMLElement` 内建成员冲突，契约登记在 `vue-prop-hijack.spec.ts`。`value` 里的未知 key 首屏保留原值但不渲染、不计名次；**首次交互后的回写只保留已知项，未知 key 被丢弃**（受控值以组件自身派生结果为准）。

**SSR**：本批登记 `NOT_SSR`（reason `pending`）。排名序列由数据属性重建、可用纯函数快照，但徽标/焦点还原与 DSD 水合路径需一并验证，本批不扩白名单；`template()` / `render()` 保持同构写法，后续白名单化只需补 `hydrate()`。
