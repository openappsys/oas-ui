# oas-image-cropper 组件说明

图片裁剪（form 族）。设计前必答清单：

1. **取消路径**：无浮层、无全局监听；`ResizeObserver` 经 `onCleanup` 断开；拖拽 / 平移状态在 `pointerup` 落定、`pointercancel` **回退到本次平移起点**（取消无副作用），断开连接时清空。`reset()` 恢复初始缩放 / 旋转 / 位移 / 裁剪框。
2. **属性默认值 / 空态**：`src` 缺省显示空态文案；`aspect-ratio` 缺省自由比例；`max-zoom` 缺省 3；`max-output-size` 缺省 1024；`output-type` 缺省 `image/png`；非法值逐项回落并单次告警。
3. **多步交互**：载入（`oas-load` / `oas-error`）→ 缩放 / 旋转 / 拖动裁剪框 / 平移图片（`oas-change`）→ 确认裁剪（`oas-crop`，canvas 不可用时 `blob: null` 并如实返回）。失败点：图片加载失败派发 `oas-error`，舞台改显错误文案（不残留破图）、不进入可裁剪态；无图时指针与滚轮都不接管（页面滚动 / 子元素交互不受影响）。
4. **破坏性选项**：无破坏性选项；`reset()` 只复位视图不删除数据；确认裁剪不改内部状态，结果交宿主。平移恒受「图片覆盖裁剪框」约束（拖 / 缩 / 转出界自动钳回），不存在「露出舞台底色」的破坏态。
5. **键盘可达 / ARIA**：裁剪框 `tabindex="0"` + 方向键移动（Shift 10px）、`Alt`+方向键平移图片（Shift 10px）；工具栏与缩放滑块为原生控件并带可读名称；`Ctrl`/`⌘`+滚轮（浏览器页面缩放）不接管；`disabled` 同步全部 `disabled` 与 `tabindex=-1`。
6. **受控 / 非受控与宿主桥接**：`src` 为受控属性；`zoom` / `rotation` / `offset` 为 JS property（`zoom` 可写且写入静默生效、不派发事件——`oas-change` 只表达用户交互，宿主按事件回写不会递归；`rotation` / `offset` 只读）；输出走 `toBlob()` / `toDataURL()` 与 `oas-crop`，宿主可直接接上传链路（裁剪产物 → `File` → 上传）。

## 交互几何口径（图片平移）

- 图片恒 cover 舞台并居中；位移 `offset` 以舞台中心为原点（旋转与位移叠加在 `transform` 上，`oas-crop` 的 canvas 反算同一份 `offset`，所见即所得）。
- 覆盖约束在**图片局部坐标**推导：把裁剪框四角反旋到图片坐标系，取四角对位移的可行区间交集；旋转 90° / 180° / 270° 与任意缩放都按同一式重算，无需分支。
- 光标锚点缩放：`offset' = a - (a - offset) × k`（`a` 为锚点相对舞台中心，`k` 为新旧缩放比），再按覆盖约束钳制。
- 可行区间退化（极端数据下图片小于所需覆盖范围）时取区间中位，保证不抖动。
