# Timeline 时间线

## 基础用法

<div class="demo">
  <oas-timeline>
    <oas-timeline-item time="2024-01-01"><p>项目启动</p></oas-timeline-item>
    <oas-timeline-item time="2024-03-01" color="green"><p>功能开发完成</p></oas-timeline-item>
    <oas-timeline-item time="2024-05-01" color="red"><p>修复线上问题</p></oas-timeline-item>
  </oas-timeline>
</div>

## API

| 属性 | 说明 |
|---|---|
| `time` | 时间文本 |
| `color` | 标记色：`green` / `red` / `gray`，默认主题色 |
