# Empty 空状态

空数据占位。

## 基础用法

<div class="demo">
  <oas-empty description="暂无数据">
    <oas-button slot="action" size="sm" type="primary">重新加载</oas-button>
  </oas-empty>
</div>

## API

| 属性 | 说明 | 默认值 |
|---|---|---|
| `description` | 描述文案 | `暂无数据` |
| `hide-image` | 隐藏插画 | `false` |

插槽：`action`（操作区）。
