# Card 卡片

## 基础用法

<div class="demo">
  <oas-card title="卡片标题">
    <p>这是一张基础卡片。</p>
    <oas-button slot="extra" size="sm">更多</oas-button>
  </oas-card>
</div>

## 可悬浮

<div class="demo">
  <oas-card title="悬浮卡片" hoverable>
    <p>鼠标悬浮时有阴影。</p>
  </oas-card>
</div>

## API

| 属性 | 说明 |
|---|---|
| `title` | 标题 |
| `hoverable` | 悬浮阴影 |

插槽：`extra`（标题右侧）。
