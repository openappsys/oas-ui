# PageHeader 页头

## 基础用法

<div class="demo">
  <oas-page-header title="页面标题" subtitle="副标题说明">
    <oas-button slot="extra" size="sm">操作</oas-button>
  </oas-page-header>
</div>

## API

| 属性 | 说明 |
|---|---|
| `title` | 标题 |
| `subtitle` | 副标题 |
| `back` | 显示返回按钮 |

| 事件 | 说明 |
|---|---|
| `oas-back` | 点击返回 |

插槽：`extra`（右侧操作区）。
