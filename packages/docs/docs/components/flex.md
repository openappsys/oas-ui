# Flex 弹性布局

## 基础用法

<div class="demo">
  <oas-flex gap="12px">
    <oas-tag>标签一</oas-tag>
    <oas-tag>标签二</oas-tag>
    <oas-tag>标签三</oas-tag>
  </oas-flex>
</div>

## API

| 属性 | 说明 | 默认值 |
|---|---|---|
| `direction` | `row` / `vertical` | `row` |
| `justify` | 主轴对齐 | `flex-start` |
| `align` | 交叉轴对齐 | `stretch` |
| `gap` | 间距 | — |
| `wrap` | 换行 | `nowrap` |
