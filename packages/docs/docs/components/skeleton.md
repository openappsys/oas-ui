# Skeleton 骨架屏

加载占位骨架。

## 基础用法

<div class="demo" style="width: 320px">
  <oas-skeleton active title avatar rows="3"></oas-skeleton>
</div>

## API

| 属性 | 说明 | 默认值 |
|---|---|---|
| `rows` | 段落行数 | `3` |
| `title` | 显示标题占位 | `false` |
| `avatar` | 显示头像占位 | `false` |
| `active` | 流光动画 | `false` |
