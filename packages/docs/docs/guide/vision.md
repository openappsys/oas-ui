# 项目愿景（Vision）

## 一句话愿景

**基础**：一套**框架无关、独立可用、TypeScript 优先**的开源通用 UI 组件库：以 Web Components 为运行时载体，兼顾 React / Vue / 原生 / Svelte 等任何宿主，让"同一套组件"在任何前端栈里开箱即用。

**追求**：功能完备、容易使用、覆盖绝大多数业务场景——引入 OAS-UI 即可撑起绝大多数业务界面，不需要再拼第二套组件。

## 为什么做

- 前端框架十年四换，但**交互行为与设计语言是相通的**——每换一轮框架，团队就重复发明一套组件。
- 主流组件库多绑定单一框架（或只支持 Vue、或只支持 React）。跨栈团队、微前端、长期演进的项目被迫维护多套实现。
- Web Components 已是浏览器原生标准（Custom Elements + Shadow DOM），2024 年后各大框架均已补齐互操作，正是"框架无关组件库"的成熟窗口期。

## 目标维度

| 维度       | 目标                                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------------------- |
| 运行时     | Web Components（Custom Elements + Shadow DOM），无框架运行时依赖，`<oas-button>` 直接可用             |
| 语言       | TypeScript 全量覆盖，导出 `.d.ts`，属性/事件有完整类型                                                |
| 工程       | Vite 构建 + Vitest 单测 + Playwright 视觉/交互测试                                                    |
| 主题       | CSS 变量设计 token + 多主题（light/dark）+ 自定义主题能力                                             |
| 国际化     | 框架无关 locale registry（不依赖 vue-i18n/react-intl）、语言包 tree-shakable、Intl.* 格式化、RTL 支持 |
| 移动端     | 触屏/窄屏适配：触控目标、bottom-sheet 移动承载、浮层视口适配——任何设备开箱可用                        |
| 双向书写   | RTL 全组件逻辑方向化（定位引擎镜像 + CSS 逻辑属性 + 方向敏感行为）+ 全量视觉审计常态化                |
| 服务端渲染 | DSD 快照直出 + 真水合（shadow 复用零闪动）+ 框架集成（Nuxt/Next）——SSR 开箱即用                       |
| 发布       | 语义化版本、文档站、demo、变更日志、可 tree-shaking                                                   |

## 设计原则

1. **原生优先**：能用地（大多数）组件直接用 `type=checkbox`、`<select>`、`<dialog>` 等原生语义/元素——可访问性、键盘行为、屏幕阅读器免费获得。
2. **无依赖优先**：运行时不依赖第三方运行时库；若需（如定位浮层）优先内联实现或选择 MIT 最小依赖，可控体积。
3. **API 对称**：属性命名对齐主流组件库的生态习惯，降低迁移成本（如 `size`、`disabled`、`loading`、`type`）。
4. **事件即接口**：组件对外通信统一走 CustomEvent，命名 `oas-*` 前缀避免冲突。
5. **可访问性即验收项**：每个组件必须过键盘导航 + ARIA + 屏幕阅读器基本检查，否则不算完成。
6. **Shadow DOM + ::part 暴露**：样式隔离默认，但通过 `::part()` 与 CSS 变量开放定制点。
7. **文档与代码同源**：组件 doc 注释、demo、测试三位一体，文档站由源码生成。
8. **性能领先**：性能是一等目标——首包体积、组件渲染耗时、交互响应必须可测量、有基准、有门槛（CI 体积/耗时预算不退化）。

## 范围边界（不做什么）

- **不做框架绑定**：不为 React/Vue 单独出 wrapper 版本——Web Components 本身可互操作；如社区需要 adapter 可作为独立子包。
- **不做应用级功能**：路由、状态管理、数据请求、SSR 数据预取不在组件库范围内。
- **不内置图标字体**：图标走内联 SVG（可 tree-shake）。
- **不内置重型图形/渲染引擎**：保持零运行时依赖与体积纪律；效果/材质类能力一律走可选独立层 + 降级链（CSS/SVG 为默认保底）。
